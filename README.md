# Network Traffic Analyzer

A Python-based network traffic analyzer built using Scapy to capture and analyze network packets in an authorized lab environment.

## Features

- Real-time packet capture
- TCP, UDP and ICMP detection
- DNS packet detection
- HTTP and HTTPS identification
- Source and destination IP extraction
- Source and destination port extraction
- Packet size analysis
- Protocol statistics
- Traffic report generation
- Wireshark validation

## Technologies

- Python
- Scapy
- TCP/IP
- Linux
- Wireshark

## Usage

```bash
sudo python3 analyzer.py
